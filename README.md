# API Integration v5

En enkel Android-väderapp gjord i **Kotlin**.

## Funktioner

* Söka efter en stad
* Visa temperatur och vind
* Spara sökningar i Firebase
* Visa sökhistorik
* 4 Fragments
* Navigation och Backstack
* Portrait och Landscape

## API

Appen använder **Open-Meteo API** för väderdata.

Geocoding:

`https://geocoding-api.open-meteo.com/v1/search`

Weather:

`https://api.open-meteo.com/v1/forecast`

## Firebase

Firebase Realtime Database används för att spara sökhistorik.

Exempel:

* Stockholm
* Göteborg

* HomeFragment
* SearchFragment
* WeatherFragment
* HistoryFragment
